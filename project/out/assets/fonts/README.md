# ฟอนต์ในเครื่อง

Kit ฝังฟอนต์ไว้เอง ไม่เรียก CDN และใช้งานได้ตอนไม่มีเน็ต

| ไฟล์ | ใช้กับ |
|---|---|
| `prompt-600/700-{thai,latin}.woff2` | หัวข้อ |
| `sarabun-400/600-{thai,latin}.woff2` | เนื้อความ |

รวม 8 ไฟล์ ประมาณ 92 KB · แยก subset ไทยกับละตินด้วย `unicode-range` เบราว์เซอร์จึงโหลดเฉพาะชุดที่หน้านั้นใช้

ที่มา Google Fonts · สัญญาอนุญาต SIL Open Font License 1.1 (แจกจ่ายพร้อม Kit ได้)

ถ้าต้องอัปเดตฟอนต์: ดาวน์โหลด woff2 ใหม่มาทับด้วยชื่อไฟล์เดิม แล้วรัน `node tools/build-kit.mjs --css-only`
