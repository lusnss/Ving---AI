# Services

- เริ่มช่วยลูกค้าจากเป้าหมายการใช้งาน: วิ่ง ซ้อม แข่ง Recovery ยืน/เดินนาน เดินทาง หรือ Outdoor
- แนะนำสินค้าตาม Use Case และประสบการณ์ที่ลูกค้าต้องการ เช่น ความนุ่ม การตอบสนอง ความมั่นคง และความคล่องตัว
- ให้ลูกค้าลอง สัมผัส ทำความเข้าใจ แล้วตัดสินใจ
- อธิบายเทคโนโลยีเป็นลำดับ: ปัญหาผู้ใช้ → วิธีออกแบบ → ประโยชน์ในการใช้งานจริง
- ช่องทางขาย: ออนไลน์ Marketplace Social Commerce ร้านเดี่ยว ห้าง Pop-up/Event และชุมชนนักวิ่ง
- ไม่ผลักรุ่นที่แพงที่สุด ไม่เริ่มจากส่วนลด และไม่สื่อสารเทคโนโลยีโดยไม่โยงประโยชน์จริง
- เงื่อนไขการขาย การเปลี่ยน/คืน การรับประกัน การจัดส่ง และการชำระเงิน: [ต้องถามเจ้าของ]
